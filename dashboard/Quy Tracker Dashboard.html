Giải Thích Chỉ Báo
MA20/50/200: Golden cross (MA ngắn cắt lên MA dài) = tín hiệu tăng mạnh.
RSI 14: <30 quá bán → cơ hội mua; >70 quá mua → cân nhắc bán.
MACD (12,26,9): Histogram dương = xu hướng tăng; âm = giảm.
Bollinger Bands: BB% <10% = NAV gần đáy dải → oversold mạnh.
Stochastic %K: <20 quá bán, >80 quá mua. Kết hợp RSI để xác nhận.
ATR%: Biên độ dao động trung bình/ngày. Cao = rủi ro lớn hơn.
Sharpe Ratio: >1 tốt, >2 rất tốt. Đo lợi nhuận điều chỉnh rủi ro.
Holding Period Return: Lợi nhuận thực tế tính theo thời gian nắm giữ thực.

📥 Đồng Bộ NAV TCBS (TCFF, TCGF, TCBF)
Chưa sync
TCBS dùng Firestore (không có REST API). Quy trình đồng bộ NAV:
1. Kéo bookmarklet vào thanh bookmark của Chrome (chỉ làm 1 lần)
2. Đăng nhập tcinvest.tcbs.com.vn → mở trang từng quỹ (TCFF, TCBF...)
3. Click bookmarklet → tải file tcbs_nav_data.json
4. Quay lại đây → nhấn "Upload File" → chọn file vừa tải
